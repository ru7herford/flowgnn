The task: predict the flow from the mesh

Steady flow at Reynolds number 40: too slow for vortex shedding, so each shape has one answer.

  1. 1 · An obstacle in a channel; the flow enters from the left

  2. 2 · SU2 (a CFD solver) computes the reference flow

  3. 3 · Each mesh point becomes a node, each mesh edge a link

  4. 4 · The GNN predicts velocity (u, v) and pressure p at each node

Four networks with different inputs

M0 gets only the mesh: it learns about the obstacle only from messages. M1 to M3 also get the obstacle distance or shape as inputs.

M1 gets only the distance rows. M2 gets only the shape rows: the same six numbers at every point (a global input). Each link also gets its length and direction.

With obstacle inputs, the network learns faster

Replay: a separate training run of M0 and M3, with the same settings.

The shape inputs cut the error the most

Distance alone decreases the error only on the airfoils.

εu = ‖uGNN − uSU2‖ / ‖uSU2 − U∞‖ over all mesh points, with u = (u, v). 0% is exact; 100% is the same as predicting the inflow U∞ everywhere.

The error is largest beyond 12 links

M0 and M1 have their largest error 15 to 60 links from the obstacle: outside their 12-link receptive field. The error also increases inside it, so the receptive field does not explain all of the error.

Influence of a point: how much the predicted u at the ringed point changes when the inputs of that point change.

Mean distance of the influence, in links

Adapted from Xu et al. (2018): the derivative of the predicted u, not of a hidden state, with respect to each point's inputs. Backpropagation computes it: reverse-mode differentiation, as in an adjoint solver.

Limits and code

A known limit, and its usual fixes

A GNN with 12 layers sees 12 links. The usual fixes: more layers, coarse long-range links (multiscale graphs), or a global input at every point (graph networks). M2 and M3 test the last one.
